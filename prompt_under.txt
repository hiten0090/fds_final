2. HARDWARE ARCHITECTURE & EDGE SENSOR TIERS
--------------------------------------------------------------------------------
A. ESP32 Main Sensor Node (Microcontroller: ESP32 DOIT DevKit V1)
   - Temperature & Humidity: DHT11 Sensor connected to GPIO 4.
     * Safe Operating Envelope: < 60°C.
     * Hazard Trigger: >= 60.0°C initiates thermal alarm.
   - Smoke & Combustible Gas: MQ-2 Gas Sensor Analog Pin connected to GPIO 34 (ADC1_CH6).
     * Baseline Clean Air: ~150 - 300 PPM.
     * Hazard Trigger: >= 1600 PPM initiates combustible gas/smoke hazard.
   - Optical Flame Sensor: Digital Active-Low IR Flame Detector connected to GPIO 13.
     * Safe State: HIGH (1) - No infrared flicker.
     * Hazard State: LOW (0) - Direct fire/flame detected optically.
   - Local Audio Alarm: Piezo Buzzer / 5V Relay connected to GPIO 23.
     * Hardware Interlock: Fires immediately when Flame == LOW or Gas >= 1600 or Temp >= 60.
   - Wireless Uplink: Connects to local 2.4 GHz WiFi (WPA2) and dispatches JSON 
     payloads via HTTPS REST POST directly to Supabase cloud table `sensor_data`.

B. ESP32-CAM Video Node (Module: AI-Thinker OV2640 Camera Module)
   - Runs high-performance MJPEG HTTP video streaming server on Port 80 (`/stream`).
   - Normal State: Standby / Armed mode to minimize power and network overhead.
   - Emergency State: Instantly activates on-demand live video surveillance in the 
     dashboard upon detection of any hazard or manual officer trigger.

--------------------------------------------------------------------------------
3. CLOUD, BACKEND & DATABASE ARCHITECTURE
--------------------------------------------------------------------------------
A. Database: Supabase Cloud Database (PostgreSQL)
   - Table Name: `sensor_data`
   - Schema Fields:
     * `id`: Auto-incrementing BigInt Primary Key.
     * `temperature`: Float / Numeric (°C).
     * `humidity`: Float / Numeric (%).
     * `gas_value`: Integer / Float (PPM).
     * `flame_state`: Integer (0 = Flame Detected, 1 = Clear / Safe).
     * `buzzer`: Boolean (true = Sounding, false = Off).
     * `fire_status`: Boolean (true = Emergency Active, false = Nominal).
     * `created_at` / `timestamp`: ISO-8601 UTC timestamp.
   - Real-time Engine: Supabase PostgreSQL CDC (Change Data Capture) via WebSockets 
     pushes newly inserted records into the React dashboard in real time.

B. Backend Server (Node.js + Express, Port 5000):
   - Endpoints:
     * GET `/api/fire/status`: Latest telemetry snapshot and system status.
     * GET `/api/fire/table`: Recent 25-50 historical database telemetry records.
     * POST `/api/fire/trigger`: Manual fire drill or remote test activation.
     * POST `/api/sms/send`: Fast2SMS / Twilio SMS gateway dispatch.
   - Camera Relay: Proxies the ESP32-CAM MJPEG stream to avoid browser mixed-content 
     or CORS restrictions.

--------------------------------------------------------------------------------
- Framework: React 18 + Vite (ES Modules, Vanilla CSS architecture).
- Data Visualizations: Chart.js 4.x running 20-second rolling real-time sliding
